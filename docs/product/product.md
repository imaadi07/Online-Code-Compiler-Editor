# Product Overview — CodeCraft Cloud Studio

## Purpose & Vision
CodeCraft is a high-performance, developer-first online code workspace and multi-file compiler. It empowers engineers, students, and educators to write, organize, test, and execute multi-file software projects across five programming languages (Python 3, Java 17, C++ 17, C 11, Node.js 20) with instantaneous sandboxed execution, zero cloud configuration, and crystal-clear diagnostics.

## Target Audience
- Software engineers benchmarking algorithms and building multi-file scripts.
- CS students learning data structures, modular software design, and standard input/output.
- Technical interviewers and educators demonstrating programming concepts in real-time.

## Key Capabilities & Features
1. **Multi-File Workspace Architecture**:
   - Hierarchical folder and file creation, deletion, and file renaming.
   - Entry point designation (`main.py`, `Main.java`, `main.cpp`, `main.c`, `index.js`).
   - Cross-file imports and modular dependency resolution.
2. **Pro Monaco Code Editor**:
   - Syntax highlighting, auto-indentation, bracket matching, line numbers, and custom font scaling.
   - Dual theme support: Obsidian Dark & Architectural Light with persistent user preference.
3. **Execution & Real-Time Diagnostics**:
   - Sub-second code execution within isolated Docker micro-sandboxes.
   - Interactive Standard Input (Stdin) stream for user prompts (`Scanner`, `input()`, `cin`).
   - Precise millisecond timing metrics and exit-code reporting.
4. **Command Palette & Keyboard Ergonomics**:
   - `Ctrl+Enter` / `Cmd+Enter`: Instant execution.
   - `Ctrl+K` / `Cmd+K`: Pro Command Palette to search files, switch runtimes, and trigger actions.
   - `Ctrl+B` / `Cmd+B`: Toggle File Explorer sidebar.
5. **Modern Animated UI & WCAG 2.1 AA Compliance**:
   - Smooth entrance reveals, scroll-driven capability showcases, tactile hover effects using Motion & GSAP.
   - ARIA live feedback, focus ring indicators, and high contrast typography.
